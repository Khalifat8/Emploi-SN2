# SENEMPLOI — HTML5, Tailwind CSS et JavaScript natif

14 pages indépendantes, images et brochures originales incluses. Aucune dépendance à React, Bootstrap ou jQuery. Le carrousel utilise Embla, inclus dans le JavaScript fourni.

## Utilisation
Aucun dossier CSS : Tailwind CSS est directement dans chaque page HTML (classes utilitaires + un script Tailwind et un bloc <style type="text/tailwindcss"> qui contient les couleurs, polices et points de rupture). Il suffit de servir ce dossier en statique ; une connexion Internet est nécessaire pour charger Tailwind.

## Connexions à rétablir
Les formulaires conservent les destinations originales https://volkodoo.pythonanywhere.com/api/v1/contacts/ et /participants/. Les deux services renvoient actuellement HTTP 404 : les envois ne peuvent pas aboutir tant que le propriétaire ne les réactive pas et n'autorise pas le nouveau domaine. Aucune réussite n'est simulée.

La traduction conserve GTranslate et nécessite une connexion Internet. La carte conserve l'intégration Google Maps. Les liens « Orateurs », « Projets innovants », « Recrutement » et les liens sociaux/politiques pointent sur # dans le HTML original : aucune destination n'a été inventée. L'image de préchargement img/preloader.svg est absente du serveur original et n'est pas utilisée.

Les images et contenus appartiennent à leurs propriétaires originaux. Le thème d'origine est TheEvent / BootstrapMade (https://bootstrapmade.com/license/).
